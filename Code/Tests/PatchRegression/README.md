# Patch regression tests

The standalone QtTest project exercises the public `Services/Patch/patch.h` API.
The fixed Git, SVN, GNU diff, and Mercurial fixtures were manually authored using
their unified-diff layouts; they are not captured output from installed VCS
tools and are not generated by the implementation under test. Separate runtime
tests produce real `git diff` and system `diff -u` output in temporary directories
and parse and preview that output. SVN and Mercurial executables are not required.

Run from a separate build directory:

```sh
mkdir -p build-local
cd build-local
/Users/loren/Qt/5.15.2/clang_64/bin/qmake ../PatchRegressionTests.pro
make -j2
codesign -f -s - bin/tst_patch_regression
./bin/tst_patch_regression
```

The signing step is needed for the local macOS 26 x86_64 Qt runtime. On other
platforms use the installed Qt 5.15.2 qmake and omit `codesign`.

Coverage includes byte-exact generation, parsing and forward/reverse previews for
UTF-8, invalid UTF-8 data, UTF-8 BOM, LF, CRLF, mixed endings and incomplete final
lines; multiple files and hunks; explicit hunk selection; exact context offsets;
ambiguous context rejection; line-numbered malformed input; path traversal and
absolute path rejection; symlink and duplicate targets; unchanged source files on
both successful and failed previews; and explicit atomic patch-file export.

The suite requires real `git`, `diff`, and `patch` executables and deliberately fails if
one is missing. Git and patch apply and reverse generated multi-file patches in
temporary directories, including Chinese and space-containing filenames. Every
result is compared byte-for-byte with the intended content.

The API currently supplies a read-only application plan. These tests do not
claim actual patch application, transaction rollback, backups, context-diff
support or git binary patch support. Only temporary fixtures are modified by
the external-tool compatibility tests.
